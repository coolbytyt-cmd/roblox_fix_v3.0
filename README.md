# Roblox CDN Fixer by: lzeo!

Простой BAT-файл, который автоматически находит рабочие IP-адреса серверов Roblox и прописывает их в системный файл hosts. Решает проблемы с загрузкой игры, текстурами и аватарами.

## Как работает

1. Создаёт резервную копию файла `hosts`
2. Удаляет старые записи Roblox
3. Проверяет доступность IP-адресов через ping
4. Прописывает только работающие IP в `hosts`
5. Сбрасывает DNS-кэш и Winsock

## Использование

1. Скачай `roblox_fix.bat`
2. Запусти от имени администратора (ПКМ → Запуск от имени администратора)
3. Выбери в меню:
   - `1` — Установить фикс
   - `2` — Откатить фикс
   - `3` — Информация
   - `4` — Выход
4. После установки **перезагрузи компьютер**

## Откат

Если что-то пошло не так — выбери пункт 2 в меню, фикс будет откачен.

## Требования

- Windows 10/11
- Права администратора
